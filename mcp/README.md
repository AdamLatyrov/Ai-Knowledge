# Локальный MCP сервер

Сервер использует транспорт stdio и не открывает сетевой порт. Codex запускает его как локальный процесс.

Корень проекта вычисляется относительно файла собранного сервера. Путь проекта и базы формируются локальным setup.ps1 и не фиксируются в общем архиве.

Приложение создаёт SQLite схему при первом запуске и предоставляет ограниченные операции retrieval, сохранения памяти, управления модулями и работы с выбранными источниками.

Подключение использует проектную конфигурацию Codex в .codex/config.toml. Codex загружает проектный слой только для доверенного проекта. Не публикуйте созданный файл, так как он содержит локальные пути.

Проектный MCP подключает Python worker только после создания .venv и сборки TypeScript через setup.ps1.
